認証済みフォロワー チェッカーベータ

X でログインすると、自分の認証済みフォロワー（青バッジのフォロワー）の人数と、収益化の条件まであと何人かが分かります。

デモ表示です。人数はサンプルで、実際の X のデータではありません。

読み取りだけの許可です（投稿・いいね・フォローはしません）。
ログインの情報は人数を1回取得したらすぐ破棄し、保存しません。

収益化の条件について
  • X の「Original Content Rewards」の条件は、認証済みフォロワー 500人以上、直近90日で認証済みユーザーからのホームタイムラインのインプレッション 50万以上（リプライは除く）、オリジナルの投稿をしていること、などです（2026年11月時点）。
  • このサイトで分かるのは認証済みフォロワーの人数だけです。インプレッションは X の Creator Studio で確認してください。
  • 条件は変わることがあります。最新の条件は X のヘルプ と Creator Studio で確認してください。
しくみ・プライバシー
  • X の公式 API を使っています。X が認証済みフォロワー数を教えてくれるのは、ログインした本人で、X Premium に加入しているアカウントだけです。
  • 求める許可は「プロフィールの読み取り」だけです。投稿・いいね・フォロー・DM の送信はしません。
  • ログインの情報（トークン）は人数を1回取得したらすぐ取り消し、保存しません。結果はこのページの中だけに表示し、サーバーには残しません。
  • サーバーで数えているのは、日付ごとの利用回数（Premium かどうか・エラーかどうかの別）だけです。アカウント名・ID・IP アドレスは保存しません。
  • 許可は X の「設定とプライバシー → セキュリティとアカウントアクセス → アプリとセッション」からいつでも外せます。
